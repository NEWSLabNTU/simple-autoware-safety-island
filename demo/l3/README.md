# demo/l3 - the RTSS@Work 2026 takeover demo (phase 8)

Design: `docs/roadmap/phase-8-rtss-work-demo.md`. This tree holds the
HPC side of the demo: the Autoware container built from the localrepo
(unit W3), the `takeover_demo` ROS 2 package (ODD monitor, takeover HMI,
availability gate, driver button, hazard relay, graph watcher), the
island gateway router configuration (unit W2), and the scenario scripts.
Recipes live in `just/l3-demo.just`.
